<h2>Условие задачи</h2>
Написать и отладить программу расчета периметра и площади равнобедренной трапеции по высоте и основанию.
<h2>Алгооритм и блок схема</h2>
1)Начало<br>
2)Ввод переменных a, b, h, c, P и S<br>
      a - большее основание<br>
      b - меньшее основание<br>
      h - высота<br>
      c - боковая сторона<br>
      P - периметр<br>
      S - площадь<br>

3)Процесс решения по формуле<br>
      c = sqrt(h * h + ((a - b) * (a - b)) / 4);<br>
	    P = a + b + 2 * c;<br>
	    S = (a + b) * h / 2;<br>
4)Вывод результата<br>
5)Конец<br>

<h2>Реализация программы</h2>
#define _CRT_SECURE_NO_WARNINGS<br>
#include <stdio.h><br>
#include <locale.h><br>
#include <math.h><br>

int main()<br>
{<br>
	setlocale(LC_CTYPE, ".UTF-8");
	float a, b, h;
	float c, P, S;

	printf("Введите большое основание a:\n");
	scanf("%3f", &a);

	printf("Введите меньшее основание b:\n");
	scanf("%3f", &b);

	printf("Введите высоту h:\n");
	scanf("%3f", &h);

	c = sqrt(h * h + ((a - b) * (a - b)) / 4);

	P = a + b + 2 * c;

	S = (a + b) * h / 2;

	printf("Периметр трапеции: %.2f\n", P);
	printf("Площадь трапеции: %.2f\n", S);

	return 0;
}<br>
